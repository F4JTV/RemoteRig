1. Principe

Deux programmes. Le serveur tourne à côté du transceiver : il partage son audio dans les deux sens, commande son PTT, et le pilote en CAT quand c'est possible. Le client tourne là où se trouve l'opérateur — sur un ordinateur ou sur un téléphone — et lui rend le poste.

Deux canaux réseau les relient. Le contrôle passe en TCP, port 7300 par défaut : authentification, état du poste, commandes. L'audio et le PTT passent en UDP, port 7301 : un datagramme perdu est oublié plutôt que retransmis, ce qui convient à de la parole. Le PTT emprunte les deux à la fois, pour qu'une perte ne laisse jamais le poste en émission.

Latence. Sur un réseau local, comptez environ 65 ms de bout en bout en Opus à 10 ms de trame, un peu moins en PCM. C'est le tampon de gigue, réglable, qui domine ce budget.

Ce qu'il faut côté station

  • Une interface audio entre le poste et l'ordinateur : carte son USB, interface numérique, ou l'audio intégré du transceiver.
  • Pour le CAT, un câble de commande et le modèle Hamlib correspondant.
  • À défaut de CAT, un simple port série dont le RTS ou le DTR commande le PTT. Vous perdez la fréquence et le mode, pas la parole.

2. Installation

Linux — Ubuntu, Debian, Raspberry Pi OS

sudo apt install ./remoterig_1.0.0_amd64.deb

Utilisez apt et non dpkg -i : les dépendances suivent. Le paquet installe le serveur, les deux clients, leurs raccourcis, les icônes et les pages de manuel.

Un paquet vaut pour une architecture : amd64 pour un PC, arm64 pour un Raspberry Pi 64 bits. Pour construire le vôtre :

./make_deb.sh
Pour piloter un poste en CAT, votre compte doit appartenir au groupe dialout : 
sudo usermod -a -G dialout $USER
Déconnectez-vous puis reconnectez-vous pour que ce soit pris en compte.

Windows

Lancez l'installateur et suivez les étapes. Il propose d'ouvrir les ports dans le pare-feu : acceptez, sinon aucun client ne joindra la station.

Android

Installez l'APK signé. Sur un téléphone Samsung, le Bloqueur automatique empêche l'installation hors boutique : désactivez-le le temps de l'installation, dans Paramètres → Sécurité et confidentialité.

Onglet Audio

Choisissez l'entrée — ce que le poste reçoit — et la sortie — ce qui part en émission. Le bouton Rechercher les périphériques prend en compte une carte branchée après le lancement.

La tonalité de PTT convient aux interfaces qui commutent le poste en détectant un signal sur le canal droit — les Digirig, notamment. La sortie passe alors en stéréo : la modulation reste à gauche, la tonalité part à droite, et elle précède le premier échantillon utile. La fréquence est réglable, 2200 Hz par défaut. Vérifiez que le poste n'est alimenté que par le canal gauche, sans quoi la tonalité serait transmise.

La taille de trame règle le compromis entre latence et robustesse. 480 échantillons, soit 10 ms, convient à la plupart des cas ; descendez à 240 sur un réseau local rapide, montez à 960 si le son hache.

Onglet Réseau

Les ports TCP et UDP, le mot de passe, et deux garde-fous :

  • Refuser les clients qui ne chiffrent pas — à activer dès que la station est joignable depuis l'extérieur.
  • Refuser l'émission hors bande — le serveur compare le spectre émis aux plages d'émission que le poste déclare, et bloque le PTT au-dehors. À désactiver pour un transverter, dont la plage de travail n'est pas celle du poste.

Sans interface graphique

Une station déportée n'a pas besoin d'un bureau. Réglez une fois avec un écran, puis :

remoterig-server --headless
remoterig-server --headless -v          # avec les changements de fréquence
remoterig-server --config poste2.ini --headless

Le paquet installe une unité systemd utilisateur :

systemctl --user enable --now remoterig-server
journalctl --user -u remoterig-server -f
sudo loginctl enable-linger $USER       # tourner sans session ouverte

Au démarrage, le serveur affiche les adresses que l'opérateur distant devra saisir, et avertit si le mot de passe est vide.

4. Le client

Se connecter

Saisissez l'adresse de la station, le port, le mot de passe, puis Connecter. Le champ UDP reste sur auto : le serveur annonce lui-même son port audio. Ne le forcez que derrière une redirection NAT qui change le numéro.

La reconnexion automatique rétablit la liaison seule après une coupure : première tentative après une seconde, puis le délai double jusqu'à trente. Pendant l'attente, le bouton devient Renoncer.

Mise en forme du micro

Quatre préréglages adaptent la modulation au micro employé. La chaîne coupe sous 300 Hz, relève la présence vers 2 kHz, coupe au-dessus de 3,2 kHz et compresse au rapport 3:1. Le vumètre d'émission indique la réduction de gain appliquée.

Réglez le niveau micro de façon que le trait de crête monte dans la zone ambre sans que le témoin d'écrêtage, à droite du vumètre, s'allume. Les trois zones du vumètre — vert jusqu'à 55 %, ambre jusqu'à 80 %, rouge au-delà — sont fixes : leur position sur l'échelle a un sens absolu, et la crête tient une seconde et demie avant de retomber.

Commande CAT brute

Un champ envoie une séquence telle quelle au poste, pour les réglages qu'aucun pilote ne couvre. Le terminateur est ajouté s'il manque, rien d'autre n'est interprété, et la réponse revient dans le journal. Il dispose de son propre onglet CAT dans le client bureau, avec un mode d'emploi de la syntaxe et son journal propre ; sur téléphone il se trouve dans le tiroir.

Chaque changement de fréquence, de mode et de VFO est relu après avoir été écrit. Les postes arrondissent au pas de leur VFO ou refusent en silence ; quand ce qu'ils annoncent diffère de ce qui a été demandé, le journal dit les deux.

5. Exploitation

Émettre

Maintenez le bouton d'émission, ou la barre d'espace sur le client bureau. Le relâchement coupe le PTT après un court maintien, réglable côté serveur, qui évite de hacher les fins de phrase.

Le bouton se grise quand l'émission est impossible : liaison absente, accord en cours, manipulation en cours, ou fréquence hors bande.

Fréquence, bandes, VFO

Les boutons de bande sont construits à partir des plages d'émission que le poste déclare : chaque transceiver affiche donc les siennes. Un clic sur l'afficheur de fréquence ouvre une saisie qui accepte 14.074, 14074 ou 14074000.

Modes et largeur de filtre

La liste des modes vient du poste : chacun affiche les siens. À côté, les trois largeurs de filtre que Hamlib normalise pour le mode courant — large, normale, étroite — exprimées en kilohertz. En choisir une applique la largeur sans changer de mode ; le poste répond ce qu'il a réellement retenu, et la liste se recale sur lui.

Coupleur d'antenne

Le bouton Accord n'apparaît que si le poste accepte la commande et répond en CAT. Pendant le cycle, l'indicateur affiche ACCORD et le PTT est verrouillé : le poste émet déjà.

ROS

La jauge sous le S-mètre n'apparaît que si le poste rapporte son ROS. Il ne se mesure qu'en émission ; la dernière valeur est conservée au relâchement, le temps de la lire, et remise à zéro à l'émission suivante. Au-delà de 2:1, le chiffre passe au rouge.

Télégraphie

Deux voies, selon ce que le poste accepte.

Le poste manipule lui-même. Le texte part par le CAT et son manipulateur électronique génère les éléments. C'est la voie la plus simple quand elle fonctionne.

Elle ne fonctionne pas partout. Sur les Yaesu HF, la commande de manipulateur ne sait que rejouer les mémoires internes du poste : envoyer AGN? déclenche la mémoire 1, quel que soit le texte. Cinq boutons appellent donc ces mémoires directement, numérotées de 1 à 5. Elles s'enregistrent sur le poste, dans les menus 04-07 à 04-11 sur un FT-891, et contiennent jusqu'à 50 caractères chacune.

Le serveur génère les éléments. Cochez Générer le CW ici et manipuler une ligne série dans l'onglet Poste, choisissez le port et la ligne, DTR ou RTS, câblée sur la prise KEY. Le réseau n'intervient jamais dans l'espacement : seul le texte voyage, la cadence est produite à côté du poste.

Le port de manipulation doit être libre : un port série ne s'ouvre pas deux fois, donc ce ne peut pas être celui que tient déjà le pilotage du poste. Les transceivers qui exposent deux ports USB, et les interfaces comme la SCU-17, vous en laissent un pour cela.

La correction raccourcit chaque élément manipulé, jamais les silences, pour compenser le temps que met le poste à établir sa porteuse. Commencez à zéro et ne l'augmentez que si vos correspondants signalent des points écourtés. La ligne peut être inversée, et le PTT maintenu pendant tout le message sur les postes qui ne commutent pas seuls.

Le panneau s'ouvre par le bouton point-trait du bandeau : vitesse, six mémoires logicielles, les cinq du poste, un champ libre, et un arrêt toujours à portée. Les mémoires logicielles utilisent %c pour votre indicatif, saisi une fois dans les réglages.

Garde-fou de bord de bande

Le serveur juge le spectre réellement émis, pas la porteuse. En USB l'émission se place au-dessus de la fréquence affichée, en LSB au-dessous. À 7,200 000 MHz exactement, la LSB reste dans le 40 m quand l'USB en sort. Quand l'émission est bloquée, le client affiche les bornes calculées.

6. Modes numériques

Le client publie une interface rigctld sur 127.0.0.1:4532. WSJT-X, fldigi ou JS8Call pilotent alors le poste distant comme s'il était local.

  1. Passez le codec en PCM 16 bits : Opus est fait pour la voix et abîme les modulations numériques.
  2. Activez l'interface rigctld — case à cocher sur le bureau, interrupteur dans le tiroir sur téléphone.
  3. Dans le logiciel numérique, choisissez le poste Hamlib NET rigctl et l'adresse 127.0.0.1:4532.
  4. Routez l'audio entre le logiciel et le client : câble virtuel sous Windows, module null-sink sous PipeWire ou PulseAudio.
Coupez la mise en forme du micro en numérique. Le compresseur et le filtre de présence sont faits pour la parole et dégraderaient un signal FT8.

7. Sécurité et réseau

Le mot de passe n'est jamais transmis : l'authentification se fait par défi-réponse, avec PBKDF2-HMAC-SHA256 et 60 000 tours. Le chiffrement facultatif protège ensuite le contrôle et l'audio par ChaCha20, avec un contrôle d'intégrité.

Un jeton de session, dérivé du mot de passe, accompagne chaque commande de PTT : un tiers qui observerait le trafic UDP ne peut pas faire émettre la station en rejouant un datagramme.

Exposer une station sur Internet demande de la prudence. Préférez un tunnel — VPN ou WireGuard — à une redirection de ports. Si vous redirigez malgré tout, activez le chiffrement obligatoire et choisissez un mot de passe long.

Surveillance du client

Un client qui disparaît sans fermer sa connexion — téléphone éteint, Wi-Fi coupé — laisserait sinon le poste en émission : TCP ne s'en aperçoit qu'au bout de dizaines de minutes. Le serveur date donc tout ce qu'il reçoit. Deux secondes de silence, PTT enfoncé, coupent l'émission ; quinze secondes libèrent la station pour un autre client.

Le micro n'apparaît pas dans la liste Sous Linux, PortAudio écarte les cartes déjà prises par PipeWire. Déclarez un PCM nommé dans ~/.asoundrc pointant sur hw:x,0. Utilisez remoterig-server --list-audio pour connaître les numéros.
« pas de CAT » alors que le poste est allumé Port série, débit ou modèle Hamlib inexacts. Vérifiez aussi l'appartenance au groupe dialout.
Le bouton d'accord ou le manipulateur n'apparaît pas Ils exigent un CAT qui répond, pas seulement un poste déclaré. Le journal affiche les capacités détectées juste après la connexion.
« Invalid configuration » à l'ouverture du poste Si le journal montre cannot get host "ttyUSB3", Hamlib a pris le nom du port pour une adresse réseau. Corrigé depuis la version 1.0.0 : le serveur transmet désormais /dev/ttyUSB3. Sur une version antérieure, saisissez le chemin complet.
Le CW envoie autre chose que le texte Le poste rejoue une de ses mémoires internes au lieu de manipuler le texte. Utilisez les cinq boutons de mémoires, ou activez le manipulateur du serveur.
Le PTT CM108 ne fonctionne pas sous Linux Droits sur /dev/hidraw*. Installez la règle udev livrée avec le projet, puis débranchez et rebranchez l'interface.
Le PTT CM108 ne fonctionne pas sous Windows Hamlib ne l'implémente que pour Linux : il ouvre /dev/hidraw, sans équivalent Windows. Utilisez la tonalité de PTT.
Le son hache Augmentez le tampon de gigue, puis la taille de trame. Sur un réseau chargé, passez en Opus si vous étiez en PCM.
Émission impossible, « hors bande » Le spectre émis sort des plages déclarées par le poste. Le message indique les bornes calculées. Pour un transverter, désactivez le garde-fou côté serveur.
Des messages ALSA défilent au lancement PortAudio sonde tous les greffons déclarés par le système, dont ceux qui ne correspondent à rien. Sans conséquence.
